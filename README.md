---

## 🚀 Task 1 Overview

In this task, I implemented Python functions to convert and standardize IoT device data from two different JSON formats into a unified structure.

### Key Concepts:

* JSON data handling  
* Data transformation  
* Working with nested data  
* Timestamp conversion (ISO → Unix milliseconds)  

### Files:

* `main.py` – Contains conversion logic  
* `data-1.json` – Input format 1  
* `data-2.json` – Input format 2  
* `data-result.json` – Expected unified format  

### Outcome:

Successfully converted both input formats into a consistent schema and passed all test cases.

## 📊 Task 2 Overview

This task involves designing a development proposal for a **Real-Time Manufacturing Status Dashboard**.

### Objective:

To create a system that provides real-time visibility into machine health across multiple factories, enabling faster issue detection and improved decision-making.

### Key Features:

* Real-time monitoring of machine status  
* Factory-wise and machine-wise dashboard view  
* Status indicators (Healthy / Unhealthy)  
* Alerts for abnormal machine behavior  
* Historical data tracking and basic analytics  
* Secure access through authentication  

### Description:

The proposed system delivers a centralized dashboard where users can monitor machine performance across factories. It allows users to drill down into specific machines, view their current status, and analyze historical trends. The inclusion of alerts ensures quick response to failures, reducing downtime and improving efficiency.

### Files:

* `task2_SoftwareDevelopmentProposal.pdf` – Complete development proposal document  

### Outcome:

Developed a structured and professional proposal outlining system design, scope, timeline, estimation, and support strategy.
